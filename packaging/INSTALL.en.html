Install Checker

macOS 13 or later · Apple Silicon (M1 or later) · Version {{VERSION}}

  1. Open the disk image and drag Checker to Applications. Quit the existing Checker app before replacing it during an update.
  2. Open Checker from Applications. In Settings & connections, select the tools you use and click Install selected connections.
  3. Chrome: open chrome://extensions, enable Developer mode, and choose Load unpacked. Use Copy folder path in Checker to find the extension folder. If it is already installed from this folder, reload it. If your old extension was loaded from a Desktop project, remove that extension and load the new folder instead.
  4. Claude Desktop: quit and reopen Claude, then enable the checker tools. Codex: use $checker-capture in a new chat.

Reopen settings with the gear button at the top of Checker or Settings & connections in its menu bar menu. You can eject the disk image after installation.

Choose your language

Checker supports English and Korean. It initially follows your system language, with English as the fallback. Choose a language in Checker settings or at the bottom of the Chrome popup. The setting is shared across the app and extension, and controls new AI-generated titles and notes. Existing tasks, notes, and custom category names stay as you wrote them.

Add any page with one click

Open the Checker extension on the page you want to keep and click Add to Checker. AI reads the page image and text, then generates a task title, note, and category. Analysis continues if you close the popup. Click a saved task title to return to the original page.

AI analysis requires the Codex app and a signed-in account, and uses that account’s usage limits. The page image and text are sent to Codex for analysis. Temporary analysis inputs are deleted afterward; your checklist stays on your Mac. Python and developer tools are included or unnecessary for installation.

Updates and your data

Quit Checker, replace the app in Applications, and reopen it. Install the connections again from settings and reload the Chrome extension. Tasks, archived items, categories, and language preferences remain in ~/Library/Application Support/Checker.

This installer contains no personal checklist, chat history, or Codex login credentials. This distribution does not support Intel Macs or Windows.
