나중에 챙길 일, 한곳에

Checker 설치하기

macOS 13 이상 · Apple Silicon(M1 이상) · 버전 {{VERSION}}

AI에게 설치를 맡기려면 AI 설치 안내의 요청 문구를 복사하세요. AI가 앱 설치를 진행한 뒤, 앱의 연결 설정 버튼을 사용합니다. macOS 실행 승인과 Chrome 확장 추가는 사용자가 확인합니다.

  1. 열린 설치 이미지에서 Checker를 Applications(응용 프로그램) 폴더로 드래그합니다. 기존 Checker를 업데이트할 때는 앱을 종료하고 교체하세요.
  2. 응용 프로그램 폴더의 Checker를 엽니다. 처음 나타나는 연결 설정에서 사용할 도구를 선택하고 ‘선택한 연결 설치’를 누릅니다.
  3. Chrome: chrome://extensions에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 누릅니다. Checker 연결 설정의 ‘폴더 경로 복사’로 가져온 폴더를 선택하세요. 이미 이 폴더의 확장을 설치했다면 새로고침하면 됩니다. 예전 바탕화면 프로젝트 폴더의 확장을 쓰고 있었다면 해당 확장을 제거한 뒤 새 폴더로 추가하세요.
  4. Claude 데스크톱: 앱을 완전히 종료하고 다시 열어 checker 도구를 켭니다. Codex: 새 대화에서 $checker-capture를 사용합니다.

연결 설정은 Checker 위쪽 톱니바퀴 또는 메뉴 막대의 ‘연결 설정…’에서 다시 열 수 있습니다. 설치 후 디스크 이미지는 추출해도 됩니다.

언어 선택

한국어와 영어를 지원합니다. 처음에는 기기 언어를 따르며 지원하지 않는 언어에서는 영어를 사용합니다. 앱의 연결 설정 또는 Chrome 팝업 아래에서 언어를 바꿀 수 있습니다. 앱·확장·새 AI 제목과 메모에 함께 적용되며, 기존 제목·메모·직접 만든 카테고리는 바꾸지 않습니다.

Chrome에서 한 번 눌러 추가

원하는 페이지에서 Checker 확장을 열고 ‘추가하기’를 누르면 AI가 화면과 본문을 읽어 제목·메모·카테고리를 정합니다. 팝업을 닫아도 작업은 계속됩니다. 체크리스트 제목을 누르면 원래 페이지로 돌아갑니다.

AI 분석에는 Codex 앱 설치와 로그인이 필요하고 해당 계정의 사용 한도를 사용합니다. 화면 이미지와 페이지 내용을 Codex에 보내 분석하며 분석용 임시 파일은 처리 후 삭제합니다. 체크리스트는 이 Mac에 저장합니다. Python이나 개발 도구를 따로 설치할 필요는 없습니다.

업데이트와 데이터

업데이트는 Checker를 종료한 뒤 응용 프로그램 폴더의 앱을 교체하고 다시 실행합니다. 연결 설정에서 설치를 갱신하고 Chrome 확장을 새로고침하세요. 기존 항목·보관함·카테고리는 ~/Library/Application Support/Checker에 유지됩니다.

이 설치 파일에는 개인 체크리스트·대화·Codex 로그인 정보가 포함되지 않습니다. Intel Mac과 Windows는 이 배포판의 지원 대상이 아닙니다.
